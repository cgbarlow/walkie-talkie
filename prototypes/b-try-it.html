A walkie-talkie with one big button, made for Grandad. It goes over Wi-Fi or mobile data, so it reaches across town as easily as across the room.

Stage 1 uses two Rabbit R1s, wiped and set up to run one app and nothing else. The side button becomes the talk button and the scroll wheel picks the channel.

How your voice gets there

Both walkies dial out to one small server. It passes the message on and keeps a copy of the last one for 24 hours, in case a walkie was off. It cannot hear what is said.

Hold the button above and watch the message move.

Locked on the walkie

Each message is encrypted before it leaves and only unlocked on the other walkies. The server routes it without opening it.

One voice at a time

Like a real radio, only one person talks. Press while someone else is talking and you get a busy tone instead.

Microphone off by default

It only listens while the button is held. No one can switch it on from afar, and the screen goes red whenever it is on.

Two stages

Stage 1 · now

Prove it on the Rabbit R1

The R1 is a small Android device with a button, a wheel, a speaker and Wi-Fi. It needs reflashing before it will run our app, but after that it does everything a walkie needs. This lets us test the server, the sounds and the screens with Grandad before building any hardware.

  • Back up, unlock and reflash both R1s
  • Build the relay server
  • Build the walkie app and lock the R1 to it
  • A week of real use with Grandad
Stage 2 · next

Build our own on an ESP32

Rabbit has stopped making the R1, and its battery only lasts a day and a half. An ESP32 is a cheap chip with Wi-Fi built in, and it can do the same job in a box we design. The server and the sounds stay the same.

  • Wire up the parts on a breadboard and check the volume
  • Adapt open-source voice firmware to our server
  • A laptop tool to load Wi-Fi and keys
  • A web page for channels, battery and alerts
  • Print a case, then a week with Grandad

111
This is not an emergency alarm. In an emergency, call 111. Each walkie comes with a printed card that says so, and it has no button marked Help or SOS. It goes alongside a monitored medical alarm, not instead of one.
